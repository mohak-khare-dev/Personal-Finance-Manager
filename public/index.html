Deploying to Netlify

This project is configured for Netlify deployment with netlify.toml and serverless functions in netlify/functions/api.py.

Step-by-Step Netlify Deployment:
  1. Push repository to GitHub.
  2. Go to app.netlify.com and click Add new site > Import an existing project.
  3. Select GitHub and choose Personal-Finance-Manager.
  4. Netlify auto-detects netlify.toml for build settings.
  5. Go to Site configuration > Environment variables and add:
    SARVAM_API_KEY = your_key_here
  6. Click Deploy site. Netlify will deploy your static frontend and serverless Python API!
